**Stop conditions:** unexpected workspace, lost/corrupt data, repeated installer failure, crash, unreachable widget, security block, or no reliable wake path. Preserve backups and contact the coordinator. A failure stays failed until a documented retest passes. Automated command tests do not replace physical checks.

Overnight stability and startup component-level timing remain unverified. Optional AI testing is separate, uses synthetic prompts, and requires proposal review; no core row requires AI.
